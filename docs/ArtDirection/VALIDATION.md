# Проверка художественного пакета

20.10.2026. Протокол различает аудит проекта, статическую проверку макетов, просмотр изображений и проверку в игре.

## Наблюдалось в этой задаче

- MCP подтвердил нужный root, Unity 6000.6.0f1, URP и открытый DevelopmentSandbox в Edit Mode. Консоль на момент исходного осмотра: 0 error entries в запрошенном текущем журнале. Это не новая компиляция.
- Сделан настоящий camera capture 960×553; исходная сцена не переключалась и не сохранялась.
- В браузере действительно просмотрены игровой склад с Oscar, магазин, уличный кадр и официальный сайт Schedule I; присланный владельцем grid также просмотрен. Найденные URL и выводы сохранены в RESEARCH.
- Финальные AI-концепты просмотрены. Исправлена неверная зелёная отметка у отремонтированного, ещё не проверенного фонаря. Ошибочные тексты первоначального A не используются как игровые правила.
- Весь новый материал находится в `docs/ArtDirection`; существующие игровые сцены, код, материалы и настройки этой задачей не редактировались. Временный файл capture в Assets удалён после переноса в docs.

## Статические результаты

- `python docs/ArtDirection/sources/verify_samples.py`: 12 UI SVG, всего 16 SVG, 7 PNG, 63 проверенные локальные Markdown-ссылки; ошибок нет. XML SVG разобран; все HTML src/href существуют.
- Проверено 78 обязательных глифов локального TTF: русские А–я, Ёё, цифры, `$`, №; отсутствующих нет. Это cmap-проверка исходного файла, не проверка TMP atlas будущей игры.
- Контраст sRGB непрозрачных пар Paper/Ink 11,40:1, Paper/Muted 5,03:1, Paper/Verified 6,08:1, Paper/Fault 5,66:1, Paper/Equipment 5,72:1. Эти результаты не распространяются на текст поверх произвольного кадра или неактивную кнопку.
- Арифметика весов проверена программно: A 4,65 / B 8,40 / C 7,40 / D 7,25. Это экспертные входные оценки, не экспериментальные измерения.
- Python sources разобраны через `ast.parse`; встроенный HTML JavaScript разобран `new Function`, без исполнения DOM. Синтаксических ошибок не найдено.
- `render_samples.cjs` через уже имеющийся bundled sharp отрендерил 7 статических образцов в игнорируемую `Temp/ArtDirection`. Визуально просмотрены HUD/диагностика/финансы при 1600×900, инвентарь при 1600×1000, сделка при 2100×900, типографический лист и схема стола. В схеме исправлено пересечение нижних подписей; финансовые значения выровнены отдельной правой колонкой.
- Форматы 16:10/21:9 в этих рендерах сохраняют центральный SVG и добавляют поля. Это проверка статической композиции, не layout/reflow Unity.
- Браузерный прогон HTML не завершён: локальный сервер/сокет был недоступен в sandbox, переход `file://` запрещён политикой browser tool. Другие приложения на localhost не исследовались и не изменялись. Открытые этой задачей временные вкладки закрыты. Клики, фокус и клавиатурная навигация HTML не объявляются проверенными.
- `git diff --check` выполнен; отдельная staged-проверка выполняется перед commit. Новые растры/TTF следуют уже существующему Git LFS. Архив/Player build не создавались.

## Чего не проверяли

- Новый арт в Unity, playable prototype новой сцены, компиляцию изменений, EditMode/PlayMode tests, реальное управление/поворот в руках, риг/анимации/звук.
- Фактические расстояния подхода и комфорт новой компоновки, коллизии будущих мешей и переноску нового ящика.
- Целевой Player, FPS/VRAM/CPU нового стиля, minimum hardware.
- Полноценный reflow 150% текста в игре, геймпад, качество самостоятельного освоения и интерес новой подачи по человеческому плейтесту.
- Юридическую доступность существующего `Male_Casual.fbx` для новых production assets и уникальность вымышленной марки ВЕРТА.

## Известные пределы образцов

- B — рекомендация, не подтверждённый выбор владельца. A был отвергнут; предыдущий округлый B также не является кандидатом.
- D недостаточно отдалился от B в растровом образце; описание более строго, чем полученный растр. Слабая отличимость учтена в оценке.
- SVG — плоские схемы, не доказательство 3D-пропорций. Растры — концепты, не game-ready ассеты и не настоящий Unity screenshot.
- HTML переключает экраны и демонстрирует статусы/одноразовый feedback. Это независимые fixtures, а не новый сквозной симулятор экономики. Передача в демонстрации не проверяет её все игровые предусловия.
- Переключатель формата стенда меняет область композиции, сохраняя центральный SVG; не моделирует динамический layout реального Canvas. Подписи внутри SVG масштабируются вместе с ним.
- Часть чисел, кириллицы и знаков должна быть проверена в реальном размере после реализации. Макет не обещает поддержку любого сверхмалого окна.
