### Камера, предмет, взаимодействие

- `PlayerController`: cameraOffset `(0,1.65,0)`, ходьба 4, sprint multiplier 1.5; fallback capsule 1.8 м / radius 0.3 м. Конкретный сериализованный collider может переопределять fallback.
- Камера активного sandbox: FOV 75°. `City Main Camera` в сохранённой CityGreybox: FOV 70°; отдельная камера машины 68° не используется как мерка интерфейса пешком.
- `PlayerRaycast`: 2.5 м, первый solid-hit блокирует дальнейшие взаимодействия. `CityTradeView.Reachable` тоже проверяет 2.5 м и видимость.
- Старый `FirstDealPropBuilder`: housing 0.24×0.28×0.18 м, foot 0.29×0.06×0.23 м, ручка выше корпуса. Весь фонарь не равен высоте housing.
- Город `CityTradeView.BuildWorld`: lamp-box 0.30×0.48×0.26 м, crate 1.25×0.35×0.65 м. Held lamp `(0.38,-0.4,0.7)`, crate `(0,-0.85,1.1)`, bench point `(-72,1.25,34)`. Три городских фонаря пока простые runtime-боксы, не автоматически наследуют старый красивый prefab.
- `WorkshopSession` и partial `WorkshopTrading`, `WorkshopOutcome`, `WorkshopCarrying`, `WorkshopPersistence` владеют операциями; `FlashlightUnit` хранит экземпляр, состояние знания и место. Есть `Changed`, `TransactionCompleted`; будущий визуал может подписываться на них. UI не должен повторять денежные расчёты.
- `CityTradeUI` уже строит uGUI через Canvas/LayoutGroup/ScrollRect и использует `LegacyRuntime.ttf`, InputSystemUIInputModule и Screen.safeArea. Эталон 1280×720, match 0.5. Нет оснований переводить это на UI Toolkit в арт-задаче. В старом inventory есть отдельные Item/InventoryManager — это не готовая единая товарная модель.

### Правила, которые нельзя смешать

| Параметр | Закрытый FIRST DEAL | Актуальный город |
|---|---|---|
| Деньги / партия | $300 / 3 за $180 | То же |
| Состояние партии | Два исправных, один дефект батареи | То же, скрытое до теста |
| A / Б | 2 за $260 / 1 за $125 | То же |
| Время A / Б | До 09:00 / 18:00 от смены | 9 / 18 минут от принятия |
| Ремонт | Батарея $50, +240 секунд, повторный тест | То же |
| RepeatB | Один повтор за $110 | Отключён |
| Выкуп | После продажи либо истечения обоих сроков | После покупки партии |
| Смена / финал | Явное завершение игроком | Нет общей смены и автофинала |

Основание городских правил — последние явно подтверждённые решения в CITY_GREYBOX_PLAN и ветвления `IsCity` в текущем коде, а не свободная художественная интерпретация. Пауза меню/потеря фокуса останавливают время. Включение F не заменяет диагностику. Ремонт сбрасывает знание; полная передача конкретных предъявленных ID атомарна.
